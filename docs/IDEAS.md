# Ideas

- Filter or merge small islands / sub-nozzle details
- Rounding, fillets, or smooth lofting between terrace layers
- GUI controls for print dimensions (layer height, outer rim width, overall scale)
- Soap dish ergonomics (drainage, soap rest height, multi-color layer swaps)
- Simple single-level loop spacer/insert for an existing soap dish
- Print-in-place gyro / fidget nested rotating levels (clearance gaps, tapered/captive rings)
- Hanging wall art & other wall hangers (reusing the geometry code for non-Mandelbrot shapes)
- Toggleable scale reference objects and build plate view
- Performance: Web Workers for off-thread meshing/contours, WebGPU for fractal/particle compute
